================================================================================
                        QUICK START (3 STEPS)
================================================================================

STEP 1: FIRST TIME SETUP (One-time only)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    cd SKS-mobile-V2
    ./setup-signing.sh

    This will:
    - Create keystore for signing
    - Create key.properties file
    - Update .gitignore

    ⚠️  SAVE YOUR PASSWORD! You'll need it for all future builds.


STEP 2: CONFIGURE ENVIRONMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    Edit .env file:
    
    API_BASE_URL=https://your-production-api.com
    ONESIGNAL_APP_ID=your_production_onesignal_app_id
    GOOGLE_CLIENT_ID=your_production_google_client_id


STEP 3: BUILD APK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    ./build-release.sh

    Select option 2 (Split APKs - Recommended)

    Your APK will be in:
    build/app/outputs/flutter-apk/app-arm64-v8a-release.apk

================================================================================
                        INSTALL ON DEVICE
================================================================================

    # Connect device via USB
    # Enable USB debugging on device

    adb install build/app/outputs/flutter-apk/app-arm64-v8a-release.apk

================================================================================
                        FOR EACH NEW RELEASE
================================================================================

1. Update version in android/app/build.gradle:
   
   versionCode 2        // Increment: 1 → 2 → 3
   versionName "1.0.1"  // Update: 1.0.0 → 1.0.1 → 1.1.0

2. Build APK:
   
   ./build-release.sh

3. Test on device

4. Distribute to users

================================================================================
                        TROUBLESHOOTING
================================================================================

ISSUE: "Keystore not found"
SOLUTION: Run ./setup-signing.sh again

ISSUE: "Build failed"
SOLUTION: 
    flutter clean
    flutter pub get
    ./build-release.sh

ISSUE: "APK too large"
SOLUTION: Use option 2 (Split APKs) in build script

ISSUE: "App crashes"
SOLUTION: Check logs with: adb logcat | grep flutter

================================================================================
                        IMPORTANT REMINDERS
================================================================================

DO:
✅ Keep keystore file safe
✅ Save passwords securely
✅ Test on real device before distributing
✅ Update version for each release
✅ Use production environment variables

DON'T:
❌ Commit keystore to Git
❌ Commit key.properties to Git
❌ Share keystore password
❌ Lose keystore file (you can't update app without it!)
❌ Use development credentials in production
